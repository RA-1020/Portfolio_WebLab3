ScentMatch

A fragrance dupe discovery platform that searches close to 70,000 fragrances. It ranks algorithmic dupes by weighted similarity across notes, accords, concentration and gender, and shows community-submitted dupes beside them with upvotes, downvotes and a side-by-side comparison.

An 18-table schema with row-level security across all of it, and similarity scoring done in stored procedures.

  • Next.js
  • TypeScript
  • Supabase
  • PostgreSQL
  • Tailwind CSS
  • GSAP

Search engine

A search engine built from scratch. Uploading a document triggers lexicon generation, then a forward index deduplicated into buckets by document ID, then a multithreaded inverted-index build in which the dataset is split, temporary indexes are built in parallel and then merged. Search runs against the inverted index. Loosely inspired by the original Google paper, The Anatomy of a Large-Scale Hypertextual Web Search Engine.

Python backend, React frontend
